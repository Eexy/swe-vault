# Cardinality

## Cardinal number

The term **cardinal number** refers to the size of a [[set]]

## Ordinal number

The term **ordinal number** refers to the order of an element in a [[sequence]]

## Cardinality of a set

Let $A$ and $B$ be any [[set]]. $A$ has the same **cardinality** as $B$ (it has the same [[#Cardinal number|cardinal number]]) if, and only if, there is a one-to-one correspondence from $A$ to $B$. In other words, $A$ has the same cardinality as $B$ if, and only if, there is a [[function]] from $A$ to $B$ that is [[function#Injective (one-to-one function)|one-to-one]] and [[function#Surjective (onto function)|onto]]

### Properties of Cardinality

Here is some properties of cardinality

For all sets $A$, $B$ and $C$

1. **Reflexive property of cardinality** : $A$ has the same cardinality as $A$
2. **Symmetric property of cardinality** : If $A$ has the same cardinality  as $B$, then $B$ has the same cardinality as $A$
3. **Transitive property of cardinality**: If $A$ has the same cardinality as $B$ and $B$ has the same cardinality as $C$, then $A$ has the same cardinality as $C$

Based on those properties we can say that two set $A$ and $B$ has the same cardinality if, and only if, $A$ has the same cardinality as $B$ or $B$ has the same cardinality as $B$

## Finite and Infinite set

A set is **finite** if, and only if, it is them empty set or can be put into one-to-one correspondence with a set of the form {1,2,...,n} for some positive integer $n$.

A set is **countably infinite** if,, and only if, it has the same cardinality as the set of positive integers $Z^+$ 

A set is **countable** if, and only if, it is finite or countably infinite

A set that is not countable is called **uncountable**

# Subset

If $A$ and $B$ are [[set|sets]] then $A$ is called a **subset** of $B$, written 
$A \subseteq B$ if and only if every element of $A$ is also an element of $B$

In other word a set $A$ is a subset of a set $B$ if every element of $A$ are
also element of $B$

## Proper subset

If we have to set $A$ and $B$ and $A$ is a subset of $B$ we say that is a
**proper subset** if there is at least one element of $B$ that's not in $B$

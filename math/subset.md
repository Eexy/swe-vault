# Subset

If $A$ and $B$ are [[set|sets]] then $A$ is called a **subset** of $B$, written
$A \subseteq B$ if and only if every element of $A$ is also an element of $B$

In other word a set $A$ is a subset of a set $B$ if every element of $A$ are
also element of $B$

**example** : $\{1, 2\} \subseteq \{1, 2, 3\}$ — every element of the left set
appears in the right set

**example** : The set of [[even number|even integers]] is a subset of $\mathbb{Z}$,
and $\mathbb{Z} \subseteq \mathbb{Q}$ (every integer is a rational number)

## Proper subset

If we have two sets $A$ and $B$ and $A$ is a subset of $B$, we say that $A$ is a
**proper subset** if there is at least one element of $B$ that is not in $A$,
written $A \subset B$

**example** : $\{1, 2\} \subset \{1, 2, 3\}$ is a proper subset since $3 \in B$
but $3 \notin A$. However $\{1,2,3\} \subseteq \{1,2,3\}$ is not a proper subset

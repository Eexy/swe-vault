# Logic connector

## Conjunction

if $p$ and $q$ are [[statement]] variables, the **conjunction** of $p$ and $q$ is 
"p and q". The conjunction is written $\wedge$ and the conjunction is denoted

$$
p \wedge q
$$

The conjunction is true if and only if both $p$ and $q$ are true

**example** : $p$ = "it is raining", $q$ = "it is cold". Then $p \land q$ = "it is
raining AND it is cold" — true only when both conditions hold

## Disjunction

if $p$ and $q$ are [[statement]] variables, the **disjunction** of $p$ and $q$ is
"p or q". The disjunction is written $\vee$ and the disjunction is denoted

$$
p \vee q
$$

The disjunction is true if and only if $p$ or $q$ is true

**example** : $p$ = "I will take the bus", $q$ = "I will walk". Then $p \lor q$ =
"I will take the bus OR I will walk" — false only when both are false

## Negation

If $p$ is a [[statement]] variable, the **negation** of $p$ is "not $p$". The
negation is written with $\neg$. When using the negation we take the opposite
truth value of $p$ so if $p$ is true then its negation is false and vice versa

**example** : $p$ = "It is raining", $\neg p$ = "It is not raining"

## Order of operation

Here is the order of evaluation of operator

1. negation
2. disjunction / conjunction

We can change the order of evaluation by using parenthesis

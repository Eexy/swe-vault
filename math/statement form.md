# Statement form

A **statement form** (or **propositional form**) is an expression made up of 
[[statement]] variables and [[logic connector]] that
becomes a statement when actual statements are subsituted for the component
statement variable

The [[truth table]] for a given statement form displays the truth values that
correspond to all possible combinations of truth values for its component
statement variables

**example** : $p \land q$ is a statement form. Substituting $p$ = "it is raining"
and $q$ = "it is cold" gives the statement "it is raining AND it is cold", which
is a statement that is either true or false

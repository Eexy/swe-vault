# Ceil

Given any real number $x$, the **ceil of** $x$, denoted $\lceil x \rceil$ is
defined as follows :

$\lceil x \rceil$ = that unique [[integer]] $n$ such that $n - 1 < x \leq n$

Symbolically, if $x$ is a real number and $n$ is an integer, then 

$$
\lceil x \rceil = n
$$

# Hamming distance function

The **Hamming distance [[function]]** is named after the computer scientist Richard W. Hamming. It's a very important function in coding theory

This function gives a measure of the "difference" between two strings of $0$'s and $1$'s that have the same length

Let $S_n$ be the [[set]] of all strings of $0$'s and $1$'s of length $n$. Define a function $H : S_n  \times S_n \rightarrow Z^{nonneg}$   as follow: For each pair of strings $(s,t) \in S_n \times  S_n$  

$$
H(s,t) = \text{ the number of position in which s and t have different values}
$$

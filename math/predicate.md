# Predicate

A **predicate** is a sentence that contains a finite number of variables and
becomes a [[statement]] when specific values are substituted for the variables

**example** :

1. The sentence "James is a student at Bedford Colleged" is not a predicate
2. The sentence "x is a student at Bedford Colleged" is a predicate that we can
   represent with a symbol $P(x)$

## Domain

The **domain** of a predicate variable is the [[set]] of all values that may be
substituted in place of the variable

## Truth set

If $P(x)$ is a predicate and x has domain $D$, the **truth set** of $P(x)$ is
the set of all elements of $D$ that make $P(x)$ true when they are substituted
for $x$. The truth set of $P(x)$ is denoted

$$
{x \in D | P(x)}
$$

# Set

A **set** is a collection of unique element. In a set the order of the elements
is not important

## Notation

### Set roaster notation

The **set roaster notation** defined a set $S$ by listing all of the element
belonging to it

**example** : The set $S$ containing 1, 2 and 3 can be write like this

$$
S = {1,2,3}
$$

### Set builder notation

The **set builder notation** defined a set $S$ by using a property $P(x)$ that
all elements of $S$ may or may not satisfy. The element in $S$ come from a
bigger set than $S$

**example** : We can defined a set $S$ containing all even number like this

$$
S = {x \in Z | x = 2a}
$$

## Equality of set

Two set $A$ and $B$ are equal if they have the same elements

## Belonging to 

We can write that an element $x$ belongs to a set with the symbol $\in$ or if we
want to specify that an element $x$ doesn't belong to a set we use the symbol 
$notin$

## Superscript

We can use $+$ and $-$ or the letters $nonneg$ to indicate that a set is
composed only of the positive or negative or nonnegative elements 

**example** : The set of all real positive numbers is $R^+$

## Common set

| Symbol | Set |
| -------------- | --------------- |
| $R$ | the set of all real numbers|
| $Z$ | the set of all integers|
| $Q$ | the set of all rational numbers, or quotients of integers|

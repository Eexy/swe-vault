# Cartesian product

Given [[set|sets]] $A_1,A_2,...,A_n$ the **cartesian product** denoted 
$A_1 \times A_2 \times .. A_n$ is the set of all [[ordered tuple]] 
$(a_1, a_2,..,a_n)$ where $a_1 \in A_1$, $a_2 \in A_2$...

With the [[set#set-builder-notation|set builder notation]] we can write it like
that

$$
A_1 \times A_2 = \{(a_1,a_2) \mid a_1 \in A_1 \ and \ a_2 \in A_2\}
$$

**example** : Let $A = \{1, 2\}$ and $B = \{a, b\}$

$$
A \times B = \{(1,a),\ (1,b),\ (2,a),\ (2,b)\}
$$

Note that $|A \times B| = |A| \times |B|$ — here $2 \times 2 = 4$ elements

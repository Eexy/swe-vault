# Composite number

An [[integer]] $n$ is **composite** if and only if $n > 1$ and $n = rs$ for some
integers $r$ and $s$ with $1 < r < n$ and $1 < s < n$

**examples** :
- $4 = 2 \times 2$
- $6 = 2 \times 3$
- $15 = 3 \times 5$

An integer greater than 1 that is not composite is [[prime number|prime]]

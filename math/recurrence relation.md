# Recurrence relation

A **recurrence relation** for a [[sequence]] $a_0, a_1, \cdots$ is a formula
thaat relates each term $a_k$ to certain of its predecessors $a_{k-1}, a_{k-2},\cdots, a_{k-i}$ 
where $i$ is an [[integer]] with $k-1 \ge 0$. 

If $i$ is a fixed integer the **initial condition** for such a recurrence relation specify the
values of $a_0, a_1, \cdots, a_{i-1}$

If $i$ depends on $k$, the initial conditions specify the values of $a_0, a_1, \cdots, a_m$ where $m$ is an integer with $m \ge 0$

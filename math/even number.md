# Even number

An [[integer]] $n$ is **even** if and only if $n$ equals twice some integer.

$$
n \ is \ even \Leftrightarrow n = 2k \ for \ some \ integer k
$$

**examples** : $4 = 2 \times 2$, $-6 = 2 \times (-3)$, $0 = 2 \times 0$ are all even

See also: [[odd number]]

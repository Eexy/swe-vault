# Ordered tuple

An **ordered tuple** that we write $(x_1, x_2,...,x_n)$ where $n$ is a positive
integer consists of $x_1, x_2,...,x_n$ together with the ordering : first
$x_1$ then $x_2$...

Contrary to a [[set]] in a tuple the order matter we can have two tuples with
the same elements in it if the order of the elements are not the same thoses
tuples are not considered equal

## Ordered pair

An **ordered pair** is a tuple of size 2

## Ordered triple

An **ordered triple** is a tuple of size 3

# Truth table

A **truth table** is a table that allow us to check the truth values of a
[[statement]] or a 
[[argument#compound-statement|compound statement]]

**example** : If $p$ and $q$ are both statement

| p | q | p ∧ q |
|---|---|-------|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

# Prime number

An [[integer]] $n$ is **prime** if and only if $n > 1$ and for all positive integers
$r$ and $s$ if $n = rs$ then either $r$ or $s$ equal $n$

**examples** : $2, 3, 5, 7, 11, 13$ are prime. Note that $2$ is the only even prime

**non-examples** : $1$ is not prime (excluded by definition), $4 = 2 \times 2$ is not prime

An integer that is not prime (and greater than 1) is [[composite number|composite]]

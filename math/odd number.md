# Odd number

An [[integer]] $n$ is **odd** if and only if $n$ equals twice some integer + 1.

$$
n \ is \ odd \Leftrightarrow n = 2k + 1 \ for \ some \ integer k
$$

**examples** : $3 = 2(1)+1$, $-1 = 2(-1)+1$, $7 = 2(3)+1$ are all odd

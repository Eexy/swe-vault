# Rational number

A real number $r$ is a **rational number** if and only if it can be expressed as
quotient of two integers with a nonzero denominator. A real number that is not
rational is **irrational**

$$
r \ is \ rational \Leftrightarrow \exists \ integers \ a \ and \ b \ such \ that \ r = \frac{a}{b} \ and \ b \neq 0
$$

The definition uses the [[existential quantifier]] ($\exists$). The [[set]] of
all rational numbers is denoted $\mathbb{Q}$ (see common sets in [[set]])

Note that every [[integer]] is a rational number (set $b = 1$)

**examples of rational numbers** : $\frac{1}{2}$, $-\frac{3}{4}$, $5 = \frac{5}{1}$,
$0.333\ldots = \frac{1}{3}$

**examples of irrational numbers** : $\sqrt{2}$, $\pi$, $e$ — these cannot be
expressed as a ratio of two integers

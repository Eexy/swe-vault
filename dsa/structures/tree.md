# Tree

![[dsa/tree.png]]

A **tree** is a datastructure which is formed of **node**. Each node in a tree
has a **parent** except for the first node of three which is call the **root**

A node that doesn't have any child is called a **leaf** contrary to a
**internal** node which represent a node with children

To organize the node we use a property that will call the **key**

## Subtree

A **subtree** consists of a node and all its **descendant**

## Level

The **level of a tree** correspond to the depth of the tree 

## Unbalanced / balanced

We say that a tree is **unbalanced** if its leafs are at differents levels. If
the leafs are all at the same level we say that it's **balanced**

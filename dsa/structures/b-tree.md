# B Tree

A **B tree** is a special implementation of a [[tree]]

The purpose of a B-tree is to be balanced which means that all the leafs must be
at the same level but it must also be wide and shallow meaning that the depts of
the tree must be restraint. In a B-tree we prefer to have a lot of node at the
same level that to have a lot of levels

## B+ tree

**B+ tree** are a special case of B tree mainly used by database. Contrary to a
B tree a B+tree store the data on leaf nodes

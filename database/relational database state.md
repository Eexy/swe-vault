# Relational database state

A **relational database state** DB of a [[relation database schema]] $S$ is a
set of [[relation]] states $DB = {r_1, ..., r_n}$ such that each $r_i$ is a
state of $R_i$ and such that the $r_i$ satisfy the 
[[relational model constraints|integrity constraints]] specified in $IC$

A database state that does not obey all the integrity constraints is called
**not valid**

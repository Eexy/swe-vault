# Index

Les indexes sont des structures de données stockés sur le disque permettant d'accélérer la récupération de données dans une [[base de donnée]] sous certaines conditions

Pour qu'un indexe soit implémenté et fonctionnel il faut qu'il existe au moins [[fichier]] ainsi qu'une [[organisation primaire]] 

Les indexes permettent de fournir un chemin d'accès secondaire c'est a dire four une chemin d'accès vers [[enregistrement]] sans avoir a toucher au fichier en se basant sur des champs d'enregistrement indexé

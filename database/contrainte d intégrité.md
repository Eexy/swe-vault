# Contrainte d'intégrité

## Contrainte d'intégrité d'entité

La **contrainte d'intégrité d'entité** dit qu'il est interdit que clé primaire est pour valeur la valeur null

## Contrainte d’intégrité référentiel

La **contrainte d'intégrité référentiel** dit que dans une [[association]] on ne peut avoir un tuple qui fait reference à un autre tuple qui n'existe pas

## Contrainte utilisateur

Ce sont les contraintes défini par l'utilisateur

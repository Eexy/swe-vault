# Etat de base de donnée relationnel

Un **état de base de donnée relationnel** $DB$ correspond à un ensemble d'[[relation#Etat de relation|état de relation]] 

$$
DB = \{r_1,r_2,...,r_n\}
$$
tel que chaque $r_i$ est un état de $R_i$ et qu'il satisfait les [[contrainte d'intégrité]].

Si un état ne satisfait pas les contrainte d'intégrité alors il est dit **invalide** sinon il est **valide**

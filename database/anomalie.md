
# Anomalie
## Anomalie d'insertion

Une **anomalie d'insertion** est une anomalie qui se créé dans la [[base de donnée]] au moment de l'insertion d'un [[relation#Tuple|tuple]]

Il existe deux type d'anomalie d'insertion :
- Problème de consistance. Si trop d'information sont nécessaire pour l'association entre deux relations l'utilisateur risque de créer une erreur en rentrant les informations
- Manque d'information : Si une relation A déprend d'une autre B pour sa clé étrangère il est nécessaire que la relation B existe avant A cependant cela ne peut pas toujours être le cas

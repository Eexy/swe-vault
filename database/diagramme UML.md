## Entité

Une [[entité]] est représenté en tant que boite avec pour première section le nom de l'entité. Cela reprend la représentation d'une classe dans un diagramme UML

## Attribut

Un [[attribut]] est contenu dans la deuxième section de la boite. 

### Attribut composé

Dans le diagramme UML un attribut composé est représenté en tant que domaine listant tout les attributs le composant.

Exemple : l'attribut `NAME` dans l'entité EMPLOYÉ

### Attribut à valeur multiple

Un attribut à valeurs multiple est représenté en tant qu'une autre classe

exemple : l'attribut `Location` dans l'entité DEPARTMENT

### Domaine

On peut spécifier le domaine d'un attribut en ajoutant un `:` suivi d'une liste de valeurs entre crocher `{}`

## Association

Dans le diagramme UML une [[association]] est appelé une **association** et une instance est appelé un **lien**

Une association binaire est représenté par une ligne reliant les différentes entité participantes

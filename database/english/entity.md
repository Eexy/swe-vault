# Entity

**Entity** : An entity is a thing or an object of the real world

## Entity type

An **Entity type** define a set of entities that share the same set of [[attribute|attributes]]

**exemple**: let's say we want to represent an enterprise. We must define all
employees. To do that we need to define an Employee entity type

## Entity set / entity collection

An **Entity set** is the collection of all entities instance in a database at anytime of a particular entity type

## Weak entity

A **Weak entity** is an entity that doesn't have [[key]]

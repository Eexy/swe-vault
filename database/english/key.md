# Key

A **key** is an [[attribute]] or a set of attribute whose value is unique for
each [[entity]]. This key can be used to identify each enity uniquely

## Super key

A **super key** is a key where we can't remove an [[attribute]] whithout
deleting the key itself

## Key candidate

When an [[entity]] has multiple key then each key is call a **key candidate**
